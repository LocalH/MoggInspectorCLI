# MoggInspectorCLI
Command line tool using MoggInspectorLib to inspect moggs

```
MoggInspectorCLI 1.0-beta
Copyright (C) 2025 LocalH

  -q, --quiet      Only output PS3 keymask mismatches and red key MOGG detection
                   to stdout
  -v, --verbose    Display more information about the MOGG header
  -p, --patch      Patch PS3 keymask if it generates a mismatching key
  -f, --files      Required. MOGGs to be inspected
  --help           Display this help screen.
  --version        Display version information.

If this tool detects a red key mogg, please contact LocalH on GitHub or Discord.
```
